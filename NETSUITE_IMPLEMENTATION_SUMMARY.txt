1. EXECUTIVE OVERVIEW
--------------------------------------------------------------------------------
This project implements an end-to-end integration between Oracle NetSuite and
Nepal Clearing House Limited (NCHL) via the National Payments Interface (NPI)
and connectIPS APIs for Lumbini Ceramic.

Key Functional Capabilities:
- Single Vendor Payments & Prepayments (Real-time CIPS and Non-real-time IPS).
- Government Tax Payments (Inland Revenue Department - IRD, Dept of Customs - DOC).
- Bulk & Batch Disbursements from Journal Entries (multi-line creditor distributions).
- Bank Fund Transfers between internal bank accounts.
- Automated Bank Account Verification against NCHL database.
- Digital Signature Signing via SHA-256 using NetSuite Certificates.
- Transaction Logging, Audit Trail, and Real-time Status Tracking.

CORE MODULES & CONFIGURATION:
1. rdmodule.js
   - Core server-side SuiteScript 2.0 module.
   - Handles OAuth token generation (/oauth/token), SHA-256 certificate signing,
     fetching bank/branch lists, CIPS batch posting, IPS batch posting,
     biller payments (IRD/DOC), and status checks.
2. rdmoduleclient.js
   - Client-side helper module.
   - Handles token generation, dynamic bank & branch lists, account verification
     call (/api/validatebankaccount), and transaction status requests from the browser.
3. npiconfig.js
   - Static configuration file storing NPI host URL, API credentials (USERID,
     USERPASS, USERNAME, PASSWORD), and Certificate ID ('custcertificatenpilive').
4. configfile.js
   - Configuration file storing 'postonapprove' boolean flag and certificate ID
     ('custcertificatensnpi').
5. genconfigfile_sl.js (Suitelet)
   - Admin UI form to generate and save 'npiconfig.js' dynamically into the
     NetSuite File Cabinet in the 'npiconfig' folder.
6. write_config_ues.js (User Event)
   - Triggered on edit of a custom configuration record to re-generate and save
     'configfile.js' to File Cabinet folder 398.
7. ns_http_module_test.js (Suitelet)
   - Diagnostic Suitelet to test token generation and connectivity to NPI.
8. justfortoken.js (Client Script)
   - Utility helper to acquire an NPI OAuth token and redirect with token parameter.
